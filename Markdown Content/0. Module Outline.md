# Module Outline: Software & Symbolic AI

## 1. Module Description

This module introduces the fundamentals of software and symbolic artificial intelligence (AI). It explains how software executes instructions, how symbolic AI represents knowledge and reasons using logical rules, how symbolic AI differs from machine learning, and how modern AI systems combine symbolic reasoning with learning-based approaches.

The module consists of five interconnected topics, progressing from basic software concepts to modern hybrid AI systems.

## 2. Target Learners and Prerequisites

**Target learners:** Beginners interested in understanding software, symbolic AI, and intelligent systems.

**Prerequisites:**

* Basic computer literacy.
* Familiarity with simple logical statements.
* No previous programming or AI experience is required.

## 3. Learning Outcomes

After completing this module, learners should be able to:

1. Explain what software is and distinguish system software from application software.
2. Describe the basic process through which computer programs execute instructions.
3. Explain the historical development and fundamental principles of symbolic AI.
4. Identify facts, rules, knowledge bases, and inference engines in a symbolic AI system.
5. Explain forward chaining, backward chaining, and basic rule-based reasoning.
6. Compare symbolic AI with machine learning, including their strengths and limitations.
7. Explain how symbolic reasoning and machine learning can be combined in hybrid AI systems.
8. Identify appropriate applications and limitations of different AI approaches.

## 5. Teaching Approach, Examples, and Activities

The module will use beginner-friendly explanations, worked examples, visual aids, and short activities to help learners understand the concepts.

Each topic should include, where appropriate:

* Clear explanations of key concepts and terminology.
* At least one worked example or demonstration.
* A useful diagram or other visual aid.
* An activity or question for learners.
* An answer with an explanation.
* References supporting factual claims.

Activities should reinforce the learning objectives rather than introduce unnecessary complexity.

## 6. Scope Boundaries

### Core Topics for Detailed Coverage

* Fundamental software concepts and the relationship between software and hardware.
* Basic program execution.
* Symbolic AI, including symbols, facts, rules, and knowledge representation.
* Inference engines and rule-based reasoning.
* Introductory forward chaining and backward chaining.
* Differences between symbolic AI and machine learning.
* The basic principles of hybrid AI.

### Topics for Brief Introduction

* Early computer and AI history.
* Operating-system internals and low-level CPU details.
* Advanced theorem proving and mathematical logic.
* Detailed neural-network mathematics.
* Advanced search algorithms and planning methods.
* Historical case studies that require additional research.
* Detailed software development practices and licensing.

These boundaries help the team prioritize introductory concepts while keeping the module manageable for beginners.

## 7. Module-Wide Activity and Assessment

At the end of the module, learners should be able to explain how software, symbolic reasoning, machine learning, and hybrid AI relate to one another.

Possible assessment activities include:

1. Identifying facts and rules in a short example.
2. Tracing a rule-based system to derive a conclusion.
3. Explaining the difference between forward chaining and backward chaining.
4. Comparing symbolic AI with machine learning in a practical scenario.
5. Describing how a hybrid AI system could combine learned predictions with explicit rules.

Answers should include explanations so learners can understand the reasoning behind each result.
