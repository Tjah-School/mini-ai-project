## 2. What Is Software?

Software is a collection of programs and related instructions that tell a computer how to perform tasks. Unlike hardware, which refers to physical components, software consists of instructions and associated data.

Two common categories are:

* **System software:** Manages computer hardware and provides services for applications. Examples include operating systems and device drivers.
* **Application software:** Helps users perform particular tasks. Examples include web browsers, word processors, and games.

### How does a program run?

A simplified execution process is:

1. A programmer writes source code in a programming language.
2. Depending on the language and implementation, the code is compiled, interpreted, or executed using a combination of these methods.
3. The runtime environment and operating system provide the resources needed to run the program.
4. The computer processes instructions and data to produce results.

For example, a Python program can calculate the sum of two numbers:

```python
a = 5
b = 3
result = a + b
print(result)
```

**Output:**

```text
8
```

The program assigns values to variables, adds the values, and displays the result.

## 3. What Is Symbolic AI?

Symbolic AI is an approach to artificial intelligence that represents knowledge using explicit symbols, facts, rules, and logical relationships.

Instead of relying only on patterns learned from large datasets, a symbolic system can use human-defined knowledge to derive conclusions.

A typical symbolic AI system contains:

* **Facts:** Statements the system treats as known information.
* **Rules:** Conditions that specify what conclusions can be derived.
* **Knowledge base:** A collection of facts and rules.
* **Inference engine:** The mechanism that applies rules to available facts to derive conclusions.
* **Search or planning mechanism:** A process for exploring possible states or action sequences when solving a problem.

These components work together to represent knowledge and reason about a problem.

## 4. Facts and Rules

Consider a simple example involving weather.

**Facts:**

* The sky is cloudy.
* The humidity is high.

**Rule:**

IF the sky is cloudy AND the humidity is high, THEN the conditions may indicate rain.

The facts describe the current situation. The rule specifies how the system should use those facts to derive a conclusion.

Notice that the conclusion is only a possibility. The rule does not prove that it will rain in the real world.

## 5. The Inference Engine

An inference engine applies the rules in a knowledge base to available facts.

A simplified reasoning process is:

1. Read the available facts.
2. Find rules whose conditions match those facts.
3. Apply a matching rule.
4. Add the derived conclusion to the known information, when appropriate.
5. Continue until the system reaches a conclusion or no further applicable rules remain.

The inference engine does not automatically know whether every rule is correct. Its conclusions depend on the knowledge, rules, and assumptions provided to it.

## 6. Forward Chaining

**Forward chaining** is a data-driven reasoning method. It starts with known facts and applies rules to derive new facts.

Consider these rules:

* Rule 1: IF a person has wings AND is a bird, THEN the person is classified as a winged bird.
* Rule 2: IF an animal is a bird AND it has feathers, THEN it belongs to the feathered-bird category.

In a more conventional animal example, suppose the knowledge base contains:

**Facts:**

* Tweety is a bird.
* Tweety has feathers.

**Rule:**

* IF an animal is a bird AND it has feathers, THEN it belongs to the feathered-bird category.

**Reasoning:**

1. The system checks the facts.
2. Both conditions in the rule are satisfied for Tweety.
3. The inference engine derives the conclusion that Tweety belongs to the feathered-bird category.

Forward chaining is useful when a system needs to discover what can be concluded from the facts currently available.

## 7. Backward Chaining

**Backward chaining** is a goal-driven reasoning method. It starts with a question or goal and works backward to determine which facts would support it.

Suppose the system wants to determine:

**Goal:** Is Tweety a feathered bird?

The system checks the rule:

* IF an animal is a bird AND it has feathers, THEN it belongs to the feathered-bird category.

It then checks whether the required conditions are satisfied:

* Is Tweety a bird? Yes.
* Does Tweety have feathers? Yes.

Both conditions are supported by the knowledge base, so the system can conclude that Tweety belongs to the feathered-bird category under the defined rule.

Backward chaining is useful when answering a specific query or checking whether a goal can be supported by known facts.

## 8. Forward Chaining vs. Backward Chaining

| Feature             | Forward Chaining                                | Backward Chaining                 |
| ------------------- | ----------------------------------------------- | --------------------------------- |
| Starting point      | Known facts                                     | A goal or query                   |
| Reasoning direction | Facts toward conclusions                        | Goal toward supporting conditions |
| Main question       | What can be concluded?                          | Can this goal be established?     |
| Typical use         | Deriving consequences from incoming information | Answering a specific query        |

Both methods use rules to reason, but they organize the reasoning process differently.

## 9. Symbolic AI and Neural Networks

Symbolic AI and neural networks use different approaches to representing and processing information.

**Symbolic AI:**

* Uses explicit symbols, facts, and logical rules.
* Can provide understandable reasoning steps when the rules and inference process are inspectable.
* Depends on the quality and coverage of its knowledge base.
* Can struggle when information is incomplete, uncertain, or difficult to express as rules.

**Neural networks:**

* Learn patterns from training data by adjusting model parameters.
* Can perform well on complex inputs such as images, speech, and natural language.
* May require substantial training data and computing resources.
* Can be difficult to interpret fully, depending on the model and application.

Neither approach is universally superior. The appropriate method depends on the task and its requirements.

## 10. Hybrid AI

Hybrid AI combines two or more AI approaches, such as symbolic reasoning and machine learning.

For example, a system could use a machine-learning model to identify objects in an image and then apply explicit rules to check whether the detected objects satisfy safety requirements.

The learning model supplies predictions, while the symbolic component applies defined constraints or reasoning rules.

Hybrid systems can combine complementary strengths, but their performance depends on the reliability of the learned predictions, the quality of the rules, and how the components interact.

## 11. Worked Example: A Simple Rule-Based System

Suppose a school uses a rule-based system to decide whether a student qualifies for a certificate.

**Facts:**

* The student attended the required sessions.
* The student passed the final assessment.

**Rule:**

IF the student attended the required sessions AND passed the final assessment, THEN the student qualifies for the certificate.

**Question:** Does the student qualify?

**Step 1:** Check the attendance fact. It is true.

**Step 2:** Check the assessment fact. It is true.

**Step 3:** Evaluate the rule. Both conditions are satisfied.

**Conclusion:** According to this rule, the student qualifies for the certificate.

This example illustrates how a symbolic system can apply explicit conditions to reach a conclusion. It does not demonstrate that the rule itself is a complete or fair certification policy.

## 12. Learning Activity

A library uses the following rules:

* Rule 1: IF a book is overdue, THEN a late-fee review is required.
* Rule 2: IF a late-fee review is required AND the fee is unpaid, THEN the account needs follow-up.

The system has these facts:

* The book is overdue.
* The fee is unpaid.

**Questions:**

1. What conclusion can the system derive using Rule 1?
2. What conclusion can it derive using Rule 2?
3. Is the reasoning forward chaining or backward chaining if the system starts with the two known facts?

### Answers and Explanations

**1.** A late-fee review is required. The fact that the book is overdue satisfies Rule 1.

**2.** The account needs follow-up. Rule 1 derives the late-fee-review fact, and that fact combines with the unpaid-fee fact to satisfy Rule 2.

**3.** This is forward chaining because the system begins with known facts and derives additional conclusions.

## 13. Summary

Software executes instructions to perform tasks. Symbolic AI represents knowledge using explicit facts and rules, then applies inference mechanisms to derive conclusions. Forward chaining starts with facts, while backward chaining starts with a goal. Neural networks learn patterns from data, and hybrid AI systems can combine learned predictions with symbolic reasoning.
