## Purpose and intended learners
This learning module introduces beginners to software and explains how symbolic AI represents knowledge and uses explicit rules to reach conclusions. It assumes no prior AI knowledge and uses a small, traceable example rather than advanced mathematics.

## Learning outcomes
By the end of the module, learners should be able to:
1. Define software and distinguish system software from application software.
2. Explain, at a high level, how source code is translated or executed as computer instructions.
3. Identify facts, rules, a knowledge base, and an inference engine in a symbolic AI system.
4. Trace a simple IF–THEN rule from inputs to a conclusion.
5. Distinguish symbolic AI from neural-network approaches at an introductory level.

## Scope
The module focuses on basic software concepts, code execution at a high level, symbolic AI, facts/rules, inference, and an introductory comparison with neural AI. It does not attempt to teach operating-system internals, advanced theorem proving, or neural-network mathematics.
