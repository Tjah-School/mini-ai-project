# Software & Symbolic AI

## 1. Project Overview

This project introduces the fundamental concepts of software and symbolic artificial intelligence (AI). It explains how software operates, how symbolic AI represents knowledge and reasons using logical rules, how symbolic AI differs from machine learning, and how modern AI systems combine symbolic reasoning with learning-based approaches.

The learning materials are organized into five interconnected topics, progressing from foundational software concepts to modern hybrid AI systems.

## 2. Target Audience

This module is designed for beginners who want to understand software, symbolic AI, and intelligent systems. No advanced knowledge of artificial intelligence is required.

## 4. Learning Objectives

By the end of this module, learners should be able to:

1. Explain what software is and distinguish system software from application software.
2. Describe how source code is translated or executed by a computer.
3. Explain the fundamental principles of symbolic AI.
4. Identify the roles of facts, rules, knowledge bases, and inference engines.
5. Describe forward chaining, backward chaining, and search-based reasoning.
6. Compare symbolic AI with machine learning.
7. Explain how symbolic reasoning and machine learning can be combined in hybrid AI.
8. Identify the strengths, limitations, and applications of different AI approaches.

## 5. Module Structure

### Topic 1: The Foundation of Software

**Responsible member:** Rafael Tjahjono

Introduces software, system software, application software, programming logic, code execution, and basic version-control concepts.

### Topic 2: The Birth of Symbolic AI

**Responsible member:** Victor Charlie

Explores the origins of symbolic AI, knowledge representation, logical rules, early AI systems, and the legacy of symbolic reasoning.

### Topic 3: How Software and Symbolic AI Work

**Responsible member:** Alexander Valentino Lukman

Explains software execution, symbolic knowledge representation, inference engines, forward and backward chaining, search, and planning.

### Topic 4: Symbolic AI vs. Machine Learning

**Responsible member:** Said Aliyev

Compares explicitly defined rules with data-driven learning, including their strengths, limitations, and practical applications.

### Topic 5: The Modern Revival: Hybrid AI

**Responsible member:** Valiant Lim

Explores how symbolic reasoning and machine learning can be combined, including their applications, benefits, and limitations.
