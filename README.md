# Software and Symbolic AI

## 1. Project Overview

This project introduces beginners to software, symbolic artificial intelligence, modern machine learning, and hybrid AI.

The learning materials are organized into five connected topics and will support three main deliverables:
- Study Guide
- Presentation
- Video Tutorial

## 2. Target Audience

Beginner learners with basic computer literacy and little or no prior knowledge of artificial intelligence.

## 4. Learning Outcomes

By the end of this module, learners should be able to:

**Software**
- Explain software layers and abstraction
- Describe how the OS manages processes and memory
- Compare AOT, interpreted and JIT execution
- Apply software engineering basics (SDLC, Agile, testing)
- Write basic SQL
- Explain cloud models, licenses and Git

**Algorithms**
- Define algorithms and compare efficiency with Big-O
- Use iteration, recursion and memoization
- Compare sorting and searching methods
- Use arrays, linked lists, stacks and queues
- Explain trees, BSTs and traversals
- Run BFS and DFS on graphs

**Symbolic AI**
- Explain Symbolic AI, its history and the AI winters
- Use propositional and predicate logic
- Compare knowledge representation methods
- Explain rule-based and expert systems
- Compare search methods for planning
- Describe symbolic NLP and its limits
- Weigh strengths and limits, and explain neuro-symbolic AI

## 12. Known Limitations

- **Introductory depth:** The materials are aimed at beginners, so each topic is introduced at an overview level rather than in full technical depth. Learners who want to go further will need more specialised resources.
- **Simplified examples:** Worked examples (e.g. logic proofs, rule-based systems, search problems) are small, toy-scale cases chosen for clarity. They do not show the scale or complexity of real-world systems.
- **Condensed presentation and video:** The Presentation and Video Tutorial summarise the Study Guide and do not include every definition, example, or activity. The Study Guide remains the most complete reference.
- **Point-in-time content:** AI, cloud services, and software tools change quickly. Content about current practices, tools, and neuro-symbolic AI reflects the state of the field at the time of writing and may become outdated.
- **Language:** All materials are written in English only, which may be harder for learners who are less confident in English.
- **Static learning format:** Activities and answers are provided, but there is no interactive practice, automatic feedback, or assessment of learner progress.
- **Rendering differences:** The Markdown files are formatted for GitHub. Tables, diagrams, or symbols may display differently in other Markdown viewers.
