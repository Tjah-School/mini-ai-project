# Software and Symbolic AI

## 1. Project Overview

This project introduces beginners to software, symbolic artificial intelligence, modern machine learning, and hybrid AI.

The learning materials are organized into five connected topics and will support three main deliverables:
- Study Guide
- Presentation
- Video Tutorial

## 2. Target Audience

Beginner learners with basic computer literacy and little or no prior knowledge of artificial intelligence.

## 4. Learning Outcomes

By the end of this module, learners should be able to:

1. Explain the difference between hardware and software.
2. Describe how programs execute instructions.
3. Explain symbolic AI and its historical foundations.
4. Describe how expert systems use knowledge bases, inference engines, and production rules.
5. Compare symbolic AI with modern machine learning.
6. Explain the purpose and limitations of hybrid AI.
