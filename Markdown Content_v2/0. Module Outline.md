# Module Outline: Software and Symbolic AI

## 1. Module Description

This module introduces the foundations of software and symbolic artificial intelligence. It explains how software operates, how symbolic AI represents knowledge and performs reasoning, how symbolic systems compare with modern machine learning, and how hybrid systems combine different AI approaches.

The learning sequence progresses from software fundamentals to symbolic AI foundations, expert-system mechanics, comparisons with machine learning, and hybrid AI applications.

## 2. Target Learners and Prerequisites

**Target learners:** Beginners with basic computer literacy.

**Prerequisites:**
- Familiarity with computers and common applications.
- Ability to follow simple IF/THEN statements.
- No prior AI programming experience required.

## 3. Module Learning Outcomes

Learners should be able to:

**Software**
- Explain software layers and abstraction
- Describe how the OS manages processes and memory
- Compare AOT, interpreted and JIT execution
- Apply software engineering basics (SDLC, Agile, testing)
- Write basic SQL
- Explain cloud models, licenses and Git

**Algorithms**
- Define algorithms and compare efficiency with Big-O
- Use iteration, recursion and memoization
- Compare sorting and searching methods
- Use arrays, linked lists, stacks and queues
- Explain trees, BSTs and traversals
- Run BFS and DFS on graphs

**Symbolic AI**
- Explain Symbolic AI, its history and the AI winters
- Use propositional and predicate logic
- Compare knowledge representation methods
- Explain rule-based and expert systems
- Compare search methods for planning
- Describe symbolic NLP and its limits
- Weigh strengths and limits, and explain neuro-symbolic AI

## 5. Teaching Approach

Each topic should contain:

1. Learning goals.
2. Beginner-friendly definitions.
3. Detailed explanations.
4. At least one worked example.
5. A useful diagram, table, or process trace.
6. A practice activity.
7. An explained answer.
8. A summary and references.

## 6. Module-Wide Activity

Use a robot operating in a room as a shared scenario.

Learners should:
- Identify the hardware and software.
- Represent a fact and rule symbolically.
- Trace a symbolic conclusion.
- Compare rule-based reasoning with learned perception.
- Propose a hybrid design and identify a limitation.
